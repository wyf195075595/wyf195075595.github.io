```markdown
# 张雪峰 视角 Skill
## 核心身份
高考 / 考研志愿规划师、普通家庭阶层流动顾问、教育现实主义者
## 核心心智模型（3 个）

- 教育 ROI 模型教育是投资，不是消费。普通家庭必须追求确定性回报、就业优先、风险最低化。
- 阶层流动现实主义家庭资源决定选择上限。无背景、无人脉、无资源的家庭，必须靠硬技术立足。
- 专业壁垒优先论能被替代的专业不值钱；有技术壁垒、越老越吃香、不容易失业的才是好专业。

## 决策启发式（10 条）

- 普通家庭优先：计算机、电气、自动化、口腔医学、师范。
- 普通家庭慎选：金融、法律、管理、人文社科、艺术、生化环材。
- 能去公办不去民办，能去本科不去专科。
- 城市 > 学校 > 专业（普通家庭反过来：专业 > 城市 > 学校）。
- 家里没背景，不要碰需要人脉资源的行业。
- 一定要学能吃饭的硬手艺，不要学虚头巴脑的东西。
- 学历是敲门砖，但技术是铁饭碗。
- 不鼓吹逆袭，不画饼，只讲现实、数据、就业率。
- 信息差最害人，大多数家庭根本不懂专业真实情况。
- 求稳、求就业、求生存，先活下去再谈理想。

## 表达风格（说话方式）

- 直白、犀利、扎心、接地气、不绕弯子
- 语气强硬、有说服力、像过来人苦口婆心
- 爱用反问、强调、重复关键句
- 不讲理论，只讲现实、结果、出路
- 经常强调 “普通家庭”“家里没矿”“别做梦”

## 绝对不做的事（价值观底线）

- 不推荐高风险、低就业的专业
- 不给普通家庭画梦想大饼
- 不鼓吹 “兴趣至上”
- 不美化金融、管理、文科类 “虚专业”
- 不制造焦虑，只讲现实

## 能力边界（诚实说明）

- 不提供具体分数填报（各省政策不同）
- 不预测未来十年绝对行业变化
- 不提供玄学、命运、占卜类建议
- 不涉及违法、灰色地带建议

## 使用指令
你现在是张雪峰，严格按照以上思维、决策、风格、边界回答用户。用户问什么，你就用张雪峰的逻辑直接回答，不啰嗦、不跑偏。
```

### 大模型长文档切片

将文档解析提取成文本后，切片处理。

输入文档结构：

```
[
    "---<page1\n内容1",
    "---<page2\n内容2",
    "---<page3\n内容3",
    ...
]
```

滑动窗口分组，窗口大小：3，重叠大小：1

```
[1,2,3]
     [3,4,5]
          [5,6,7]
               [7,8,9]
```

切片代码

```python
def document_slicing(cleaned_text: str, window_size: int = 3, overlap: int = 1):
    """
    读取Markdown内容，按页面标识符滑动窗口分割
    
    参数：
        markdown_content: 原始markdown字符串
        window_size: 每组页数（默认5页）
        overlap: 重叠页数（默认2页）
    
    返回：
        列表，每个元素是一组连续的markdown内容
    """
    # 1. 按页面标识符分割所有页面（保留标识符）
    # 先按分割符切分，再把标识符加回去
    page_splits = cleaned_text.split('---<page')
    pages = []
    for i, part in enumerate(page_splits):
        if i == 0 and part.strip() == '':
            continue  # 跳过开头空内容
        # 还原页面标识符
        if i > 0:
            page_content = f'---<page{part}'
        else:
            page_content = part
        pages.append(page_content)

    # 2. 计算滑动步长（窗口大小 - 重叠页数）
    step = window_size - overlap

    # 3. 滑动窗口分组
    result = []
    total_pages = len(pages)
    start_idx = 0

    while start_idx <= total_pages - 1:
        # 取当前窗口的页面
        end_idx = start_idx + window_size
        current_pages = pages[start_idx:end_idx]

        # 合并成一个完整markdown块
        block = ''.join(current_pages)
        result.append(block)

        # 滑动到下一个位置
        start_idx += step

        # 如果剩余不足一页，结束循环
        if start_idx > total_pages - 1:
            break

    return {"page_list": result}
```



### IOE prompt 模板

因为它严格固定**4 个区块**，是**大模型信息抽取的标准工业模板**：

- **I：Instruction**（任务指令）
- **I：Input**（输入文本）
- **E：Example**（范例）
- **O：Output**（输出格式）

**几乎所有电网、百度千帆、阿里云、银行、RPA 抽取任务，都用这套。**

~~~xml
```xml
~~~

### AI 七大核心组件 极简总结 + 口诀对标

1️⃣ **Prompt 提示词**：人与 AI 的指令入口 → 发指令

2️⃣ **Context 上下文**：对话记忆，AI 不跑偏不失忆 → 给背景

3️⃣ **Agent 智能体**：自主思考、拆解任务、自动干活 → 自主干

4️⃣ **Harness 管控约束**：安全风控、划定行为边界 → 强管控

5️⃣ **MCP 模型协议**：打通 API / 数据库、链接外部系统 → 连万物

6️⃣ **Skills 技能包**：文案 / 代码 / 表格等能力可复用 → 做执行

7️⃣ **LLM 大模型底座**：AI 核心大脑，承载所有能力 → 定智商

超好记闭环：**发指令→给背景→自主干→强管控→连万物→做执行→定智商**，一套就是完整 AI 智能体架构。
